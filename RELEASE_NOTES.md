A simpler Setup page.

- Setup is now four steps in order: find World of Warcraft, pick your version, add your CurseForge API key, and sync your addons.
- Your API key is checked with CurseForge as soon as you load or type it, and the matching CurseForge edition is filled in for Retail, Classic Era, and Forever.
- **Sync my addons** saves your setup, recognises the addons you already have, and checks them for updates in one go.
- The offline demo and the manual folder text box have been removed. Use **Browse for the WoW folder** for installations the search does not find.
